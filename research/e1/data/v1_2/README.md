# v1.2 surname policy sweep

The experiment uses the first 1,000 alphabetic Census surname rows in file order and normalizes their Census counts. Each font–size cell draws 2,000 targets with replacement from that prior and draws pen x and baseline from the harness ranges, using the paper's unit seed scheme. All policies within a cell reuse the same draws. A1 knows the pen, baseline, font, size and policy and scores with the matched candidate geometry. The scorer uses expected top-10 hits for ties.

Bits are prior entropy minus the sample mean of the conditional posterior entropy. The analytic padding column is the prior-weighted class entropy, averaged over the font–size cells in scope. The 95% percentile intervals resample individual target rows 10,000 times within each reported pool using the same bootstrap draws for each policy. The area ratio divides by the same target's padded tight-box area, then takes the median across target rows. No intermediate font medians are averaged.

The fixed field spans from the shared left anchor to the widest padded right edge across the list. `field_widths.csv` records its width and the first surname attaining it in each font–size cell.

## Historical control and renderer provenance

The published start-aligned 128-px check uses the original 50,000-surname candidate list and its original sampled targets. It is in `paper_control.csv`; the new 1,000-surname results are in `summary.csv`.

Five fonts were freshly rendered in Linux under Pillow 12.3.0, with their SHA-256 hashes checked against the repository manifest. The pinned Noto Sans binary was unavailable. Its layout geometry comes from the retained prior run and was verified against archived A1 per-target top-10 and entropy for all four square grids and against the 128-px control's top-10, entropy and area. The archived area ratios recover the full-line height. Noto's full-line output top and bottom coordinates use a vertically translated line of that height enclosing the candidate boxes. This translation leaves the equality check, A1 scores and areas unchanged. Square-grid coordinates use the retained layout bounds and sampled pen and baseline. The paths and hashes needed to identify replay inputs are described below and recorded in `run.json`.

## Commands

With the full hash-verified Census CSV and the six hash-verified fonts, use the Linux study environment and run:

```sh
E1_CENSUS=/path/to/Names_2010Census.csv E1_FONT_DIR=/path/to/fonts \
  python scripts/run_v12.py
python scripts/regenerate_tables.py
shasum -a 256 -c research/e1/data/v1_2/SHA256SUMS
```

For the Noto replay performed here, append `--noto-cache /kit/results/e1-full/data/cache --noto-scores /kit/review4_grouped`, where `/kit` is the retained experiment directory. The run used the local `guard-e1-review4-forms` Docker image with networking disabled and `OPENBLAS_NUM_THREADS=1`. The table and PDF are generated by `regenerate_tables.py` under `out/`.
