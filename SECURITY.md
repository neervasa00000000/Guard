# Security

TileSeal checks the cryptographic integrity of retained image pixels and reports whether the signing key is trusted by the verifier. The implementation has not had an independent security audit. See the [security model](SECURITY_MODEL.md) for assumptions and limits.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/neervasa00000000/Guard/security/advisories/new). Include the affected revision, reproduction steps, and a synthetic fixture if one is needed. Keep private keys, personal images, and sensitive report details out of public issues.
