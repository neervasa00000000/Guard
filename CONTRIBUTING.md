# Contributing to TileSeal

Start from the current `main` branch and submit changes through a pull request. Keep the paper revision `f8f2558` available as published. Describe the user impact and how you verified the change.

Run the [build and test commands](README.md#build-and-test). For browser changes, rebuild both standalone pages and follow the [browser test plan](TILESEAL.md). Use synthetic images and test keys for fixtures. Keep private keys and personal images outside the repository.

For a vulnerability, use the [private reporting instructions](SECURITY.md).
