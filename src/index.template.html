    Privacy, plainly.

    Images and .GRD files are checked and converted on your device. Guard does not upload their contents, add analytics or store them in browser storage. Downloaded files remain on your device.

    This website is hosted on GitHub Pages. GitHub logs and stores visitors’ IP addresses for security, even when they are not signed in. See GitHub Pages data collection and GitHub’s Privacy Statement. Download the viewer and disconnect to use it without contacting the host.

    New browser conversions omit the original filename from the signed public label. Existing files may contain public labels and other metadata, also included in reports. Review them before sharing. Exported files include retained pixels, signer fingerprints and redaction information; blackout cannot remove copies someone already has.
