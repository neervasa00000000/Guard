          Your signer key

          Create or unlock a signing key

          Create once, then unlock your saved key to sign offline. Recipients must independently trust your public key before your name shows as verified. Your name is included in signed files. This does not certify your identity.

          Create a signer

          Use a unique password of at least 12 characters. Save the encrypted key file and a backup. Lost passwords cannot be recovered. Keep your key private.

          Unlock a saved signer

          No signer unlocked. Pictures use a disposable self-signed key.

          Share only the public signer file and fingerprint. The unlocked key stays in memory until you lock it or close/reload this page. Browser access or malicious scripts can still use an unlocked key. Lock it when finished.

          About Guard

          Privacy and hosting

          What the verdicts mean

          01 / INTEGRITY

          Unchanged signed bytes.

          The section hashes, image binding and signature pass against this viewer’s pinned key. This does not independently prove authorship or ownership.

          02 / PRIVACY

          No uploads.

          Checks run on your device. Download the HTML viewer to use it offline in a current browser.

          03 / LIMITS

          Viewing controls aren’t DRM.

          Screenshots cannot be reliably blocked. Timestamp validation and copy tracing are not performed by this viewer.

          Limits

          PNG, JPG, WebP, GIF or BMP. Up to 256 MiB and 50 megapixels; large photos fit GRD3’s 36-megapixel output limit. Animation uses the first frame. Transparency becomes white; source metadata is not copied. Export HEIC or PDF to PNG or JPG first.

          Viewing stamps do not prevent screenshots. Blackout only: positions and sizes of hidden areas stay visible. Redactor identity is not attested. Signed claims do not prove ownership or capture time. Timestamp tokens are not validated here. A signature does not prove a picture is true or establish ownership.

          Privacy and hosting

          Privacy, plainly. Effective 29 October 2026.

          Who runs this. Guard is an open-source project published at github.com/neervasa00000000/Guard. Questions or privacy requests: https://github.com/neervasa00000000/Guard/issues.

          What Guard does with your files. Images and .GRD files you choose are read, checked and converted only inside your browser. Guard does not upload their contents, use analytics, cookies or trackers, or store files in localStorage, IndexedDB or a service worker. Files you download stay on your device.

          Offline signing keys. Guard downloads a password-encrypted key file. Unlocked signing keys stay in memory until locked or this page closes/reloads; Guard does not save them in browser storage. Keep the encrypted file and password private. Public signer files contain a name, public key and fingerprint. Imported people are trusted only for this tab and are cleared on reload. Older offline viewers cannot know about newer revocations.

          What the website host collects. This site is served by GitHub Pages. When your browser loads the page, GitHub receives standard request data, including your IP address, and logs it for security, even if you are not signed in to GitHub. Guard cannot see or control those logs. See GitHub Pages data collection and the GitHub General Privacy Statement. To avoid contacting the host, use Download offline viewer, disconnect, and open the saved file.

          Personal information inside files. A .GRD can contain a public label, signer name, signer fingerprint, image dimensions, retained pixels and a list of hidden areas. Labels and file names may identify people, for example "passport_jane_smith.jpg". Disposable-key conversions leave the label blank and download as image.GRD. Signing with a saved signer includes the name you entered in the signed file and public signer file. Verification reports you save include these details. Check files and reports before sharing them.

          Redaction limits. Exports replace hidden areas with solid black. Anyone who already has the original or an earlier copy still has those pixels. Surrounding details can still identify a person.

          Links. Opening the source or privacy links contacts those sites. This page sends no referrer.
