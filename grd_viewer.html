    Drag a rectangle or select tiles. Areas round up to 64px blocks. Blackout removes original pixels; blur can still retain private details.

    Choose Mark tiles, then select the areas to hide.

    Retained pixels match the signed original. Redactor approval is not attested. The file label and signer fingerprint remain public.

    GRD1 signs the entire image. Redaction needs a GRD2 file issued with tile commitments; an existing GRD1 cannot be upgraded without its signer.
